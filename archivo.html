Archivo documental · Expedientes y evidencias

Un hecho puede tener muchas pruebas.

El archivo está organizado por expedientes. Cada expediente puede reunir varias publicaciones, videos, imágenes, documentos o testimonios relacionados con el mismo hecho. Abre una ficha para ver qué ocurrió, quién aparece, cuándo, dónde, por qué se investiga y qué evidencia lo sostiene.

CÓMO FUNCIONA

Expediente = el caso.
Evidencia = cada pieza que lo sustenta.
Conexión = vínculo editorial con otro expediente.
Verificado = solo lo corroborado.
